# Connect UERJ 🎓

> **Projeto de Trabalho de Conclusão de Curso (TCC) — UERJ**

O **Connect UERJ** é um ecossistema digital desenvolvido com o objetivo de centralizar informações institucionais, simplificar o acesso a dados acadêmicos e promover a integração e permanência estudantil na **Universidade do Estado do Rio de Janeiro (UERJ)**. 

Inspirado em dinâmicas de plataformas colaborativas e comunidades de discussão (estilo Reddit), o projeto busca resolver a fragmentação de informações na universidade, oferecendo um espaço único, transparente e interativo para a comunidade universitária.

---

## 🎯 Objetivos do Projeto

- **Centralização de Informações:** Agrupar avisos, eventos, dados de disciplinas e orientações acadêmicas em uma única plataforma.
- **Engajamento Estudantil:** Criar um canal colaborativo para troca de experiências, material de estudo e discussões entre discentes e docentes.
- **Facilidade e Acessibilidade:** Proporcionar uma interface simples, intuitiva e acessível para o dia a dia universitário.

## 🛠️ Tecnologias e Linguagens Utilizadas
